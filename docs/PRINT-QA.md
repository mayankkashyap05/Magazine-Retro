## Known issues (open)

1. **Sheet-level layout:** the cover fills about two-thirds of its sheet; the rest is empty. The hero was not stretched.
2. **Timeline clipping:** on the ENIAC timeline, some right-hand headings (e.g. "MICROPROCESSOR") run to the sheet edge. Not resolved.
3. **Fallback glyphs:** a few symbols (e.g. ⏚, ≈, ■) are not in IBM Plex Mono. Chromium substitutes DejaVu Sans Mono or DejaVu Serif for them. Text remains searchable; the glyph shapes differ slightly.
4. **Letter-spaced labels extract with spaces** (e.g. "E N I A C") because of the mono tracking. Search and copy still work, but may need normalising in other tools.
5. **Colour:** dark sections are printed as full ink fields in RGB. The PDF is not CMYK, not PDF/X, and has not been preflighted for commercial print.
6. **File size:** 16.65 MB, not optimised.
7. **Colour tokens:** the brief's example colours (`#F3EFE6`, `#B65F32`) differ from the repository's tokens (`#f4efe4`, `#c8401a`). The repository tokens were used.
8. **Windows:** the pipeline is cross-platform Node, but it was run only on Linux in this environment.
